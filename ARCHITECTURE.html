03 / ASYNC

Interrupt paths

Audio timing remains stable while rendering spans several frames. Floor shading changes at precise scanline boundaries.

sequenceDiagram
  participant Game as C main loop
  participant AtariOS as Atari OS VBI
  participant Audio as MELODY ASM
  participant Video as ANTIC display DMA
  participant Floor as FLOORDLI ASM
  participant Sound as POKEY audio
  Game->>Game: Update and render
  Video-->>Floor: DLI at floor band
  Floor->>Video: Write WSYNC and COLPF0
  AtariOS-->>Audio: Deferred VBI vector seven
  Audio->>Sound: Update four audio channels
  Audio-->>AtariOS: Chain saved VBI
  Game->>AtariOS: Wait for vertical blank

Display-list interrupt

Installed at VDSLST $0200. It waits on WSYNC, rotates six luminance values, writes COLPF0, and returns with RTI.

Deferred vertical blank

Installed atomically through SETVBV $E45C. It updates melody, threat, and laser channels, then chains to the OS routine saved from VVBLKD $0224.

cc65 runtime

XEX startup and exit, BSS setup, a 1 KB software C stack, constructors, waitvsync(), get_tv(), stdlib, and stdio.

DOS 2.5

The loader reads the XEX and calls RUNAD. Resident FMS later services only levels 3-5; levels 1-2 come from embedded data.

05 / I/O

Hardware registers

All addresses are in the 6502 memory map. Writes here bypass OS abstractions unless an OS shadow is explicitly named.

ChipRegistersRole
POKEYAUDF1-AUDF4 / AUDC1-AUDC4 $D200-$D207, AUDCTL $D208Four-channel melody, threat tone, and laser noise.
POKEYKBCODE $D209, RANDOM $D20A, SKSTAT/SKCTL $D20FHeld-key polling, random seed, and keyboard/audio initialization.
GTIAHPOSP0-3 $D000-$D003, missile positions $D004-$D007, sizes $D008-$D00CPositions and scales targets, pursuer, laser, exit, and decoy.

06 / ADDRESS

Memory map

Linker regions come from chased3d.cfg. Exact symbol ends come from Chased3D.lbl after each build.

$0000
OS zero page
$0082
cc65 ZEROPAGE / EXTZP through $00FF
$0100
6502 hardware stack
$0200
OS vectors and shadow registers
$0600
PAGE6 DLI code, data, and BSS through $06FF
$0700
DOS 2.5 and OS-managed RAM
$1C20
Free / reserved gap below game load address
$4000
XEX startup, game code, tables, data, and ordinary BSS
$9C00
1 KB cc65 software C stack below $A000
$A000
SCREEN, DLIST, PMGRAM, HIGHBSS beneath disabled BASIC ROM
$C000
OS ROM and hardware windows through $FFFF

SCREEN is 4 KB aligned; DLIST and PMGRAM are 1 KB aligned to satisfy ANTIC DMA addressing boundaries.
